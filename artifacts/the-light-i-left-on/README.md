# THE LIGHT I LEFT ON

TLILO-001 · 0.2.0 · WORKING CANDIDATE / UNSEALED

A static, authored 360 departure artifact. Seven pre-authored phases unfold over twelve calendar months after an actual recorded departure. No human return is inferred.

- Architecture: [complete package](docs/ARCHITECTURE.md)
- Experience: `dist/index.html`
- All-phase review: `dist/review.html` (removed before final seal)
- Configuration: `dist/release.json`
- Validate: `npm test` then `npm run verify`
- Rebuild manifest after any deployed byte change: `node tools/manifest.mjs dist`
- Prepare departure release: see [operations](docs/08_BUILD_DEPLOY_AND_RECOVERY.md)

The actual departure and NORTH destination are not recorded. This is not the sealed departure release. TB-SUB-001 v1.0.0 is unchanged; no full substrate/MIA enforcement claim.

Phone viewing: Enter, tap Enable motion, and allow orientation access. Center view resets the tilt. Sensors remain local; no location or geographic heading is requested.
