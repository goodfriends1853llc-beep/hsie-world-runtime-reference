# WRB-001 Phase 2 Contracts

This directory contains exactly seven top-level Slice 001 contracts: World, Place, Business, Representation, Topology, Request, and Event.

All seven use JSON Schema Draft 2020-12 and `schema_version = hsie-world-reference/0.1`.

`Space` is deliberately embedded within the Place contract for Slice 001 and is not an eighth top-level contract.

These are reference implementation contracts, not canonical civilization law.
