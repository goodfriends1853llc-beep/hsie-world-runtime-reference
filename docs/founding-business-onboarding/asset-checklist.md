# Founding Business — Asset Checklist

## Minimum build-ready set

- [ ] Exact public business name
- [ ] Approved short description
- [ ] Primary customer action
- [ ] Working action destination
- [ ] At least one usable identity/reference asset
- [ ] Explicit “do not use/show” notes
- [ ] Authorized submitter confirmed
- [ ] Asset-use authorization confirmed

## Preferred visual set

- [ ] Transparent PNG/SVG logo
- [ ] Storefront / exterior photos
- [ ] Interior photos
- [ ] Product / service photos
- [ ] Vehicle / equipment photos where relevant
- [ ] Brand colors
- [ ] Brand fonts or font direction
- [ ] Menu / flyer / price sheet
- [ ] Owner/team photos only when intentionally part of the build
- [ ] Existing website / social links
- [ ] Visual references for mood/atmosphere

## Action assets

- [ ] Phone/text number
- [ ] Website
- [ ] Booking link
- [ ] Menu/order link
- [ ] Quote/request form
- [ ] Directions/address
- [ ] Email/inquiry route
- [ ] Social link

Only collect what the build actually needs. More data is not automatically better.
