# Founding Business — Publishing Checklist

## Record integrity
- [ ] Business Entity record exists
- [ ] Intake Event preserved
- [ ] Asset provenance recorded
- [ ] Build brief version identified
- [ ] Approval Event recorded
- [ ] Approval applies to the exact build being published

## Representation
- [ ] Place exists independently of panorama
- [ ] Representation references correct Place / Space
- [ ] Panorama is valid 2:1 equirectangular when used as 360
- [ ] Delivery resolution is not misrepresented as native generation detail
- [ ] Visual domain matches approved brief
- [ ] No unapproved claims or people

## Interaction
- [ ] Hotspots are icon-only
- [ ] Accessible labels are present
- [ ] MOVE actions resolve through topology
- [ ] Primary commercial action works
- [ ] Secondary actions work
- [ ] Return path works when required
- [ ] No raw panorama URL is used as movement topology

## Mobile
- [ ] Loads on iPhone/mobile browser
- [ ] Touch navigation works
- [ ] Motion mode tested when used
- [ ] Hotspots are reachable
- [ ] No obvious black gaps / broken edges
- [ ] Panorama wrap visually checked
- [ ] Transition overlay does not block interaction

## Publication
- [ ] Semantic world records updated only if required
- [ ] Deterministic snapshot/tests refreshed if semantic data changed
- [ ] GitHub Actions pass
- [ ] GitHub Pages deployment passes
- [ ] Public URL verified
- [ ] Publication receipt created
- [ ] “You’re live” message sent

A checked box represents a recorded check, not an automatic guarantee outside the evidence actually captured.
